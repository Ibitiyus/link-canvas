# ZIN Stage 6: анимация и визуальные эффекты

## Использование

Выберите любой блок или группу и откройте «Анимация и эффекты» в настройках (на телефоне — в нижней панели).

Анимации: вращение, покачивание, парение, пульсация, мягкое мерцание, glitch, появление, скольжение и увеличение при появлении. Можно выключить эффект, задать длительность цикла 0,8–30 секунд, интенсивность 0–1, задержку до 30 секунд, однократный/бесконечный повтор и обычное/обратное/чередующееся направление. Для вращения один цикл означает полный оборот. Длительность — обратная мера скорости: меньше секунд означает быстрее.

Кнопка «Воспроизвести анимацию» временно запускает выбранный эффект на один цикл с учётом задержки. Переключатель «Показывать анимации в редакторе» включает воспроизведение всех настроенных эффектов; по умолчанию выключен и не входит в проект. Параметры сохраняются и поддерживают Undo/Redo. Во время захвата/перемещения/размера/поворота анимация снимается, затем запускается заново. Ручки остаются на исходной геометрии.

Hover: увеличение, наклон, свечение, прозрачность, подпрыгивание. Работает только при `(hover: hover) and (pointer: fine)`; касания не запускают эффект. В редакторе hover также требует включения воспроизведения.

Независимые визуальные настройки находятся в свёрнутом разделе: свечение, тень, размытие, яркость, контрастность, насыщенность, оттенок и grayscale. Фильтры применяются к содержимому вместе с подложкой, не переписывают сохранённый цвет или alpha фона. Имеются отдельные кнопки сброса анимации и визуальных эффектов. Демонстрации в панели проигрываются один раз.

## Архитектура

Общий `Canvas` используется редактором, предпросмотром и публичной страницей. Позиционирующий контейнер хранит grid/left/top/width/height и авторский поворот. Внутри `EffectSurface` располагаются три слоя:

1. `.effect-animation` — CSS keyframes transform/opacity.
2. `.effect-hover` — независимые transform/filter/opacity при наведении.
3. `.effect-visual` — ограниченный набор CSS-фильтров.

Масштаб всего полотна остаётся во внешнем `CanvasViewport`. Анимации не записывают координаты, не влияют на расчёт extent и не запускают React-рендер на каждом кадре. Для группы с эффектами создаётся общий контейнер по мировым границам участников; внутри сохраняются их относительные координаты и собственные повороты/эффекты. Поэтому групповое вращение выполняется вокруг общего центра, а не вокруг каждого блока отдельно. Порядок группы соответствует существующей общей модели слоёв.

`IntersectionObserver` приостанавливает CSS timeline за пределами видимой области, `visibilitychange` — в скрытой вкладке. При `prefers-reduced-motion: reduce` анимации полностью отключаются, контент остаётся видимым, hover не двигает элементы. Циклы мерцания и glitch ограничены минимум двумя секундами; мерцание плавное, с изменением непрозрачности не более 18%, без вспышек яркости. Размытие ограничено 12 px, тень/свечение — 24 px; остальные пределы заданы в `VISUAL_LIMITS` и продублированы сервером.

## Данные и выпуск

Версия проекта остаётся `1`. Необязательное поле `effects` добавляется отдельно блоку и группе:

```json
{
  "animation": {
    "enabled": true,
    "type": "float",
    "duration": 3,
    "intensity": 0.5,
    "delay": 0,
    "repeat": "infinite",
    "direction": "normal"
  },
  "hover": "glow",
  "visual": {
    "glow": 4,
    "shadow": 0,
    "blur": 0,
    "brightness": 1,
    "contrast": 1,
    "saturation": 1,
    "hue": 0,
    "grayscale": 0
  }
}
```

Все три подраздела необязательны. Когда подраздел указан, его поля валидируются. Старые проекты без `effects` сохраняют прежний вид и не получают новые поля при чтении. Метаданные проходят localStorage, JSON с файлами, облачные черновики и публичные снимки; хранение файлов в IndexedDB/Storage не изменено.

До выпуска frontend примените **новую** миграцию `supabase/migrations/202610210004_animations_effects.sql` обычным процессом после предыдущих миграций, без `db reset`. Она добавляет валидатор эффектов и расширяет текущую серверную проверку проекта. Старые миграции и сохранённые проекты не меняются. Production Supabase, Vercel и секреты в этой задаче не изменялись.

## Проверка в браузере

1. Откройте `/editor`, выберите текст/фото, назначьте парение. В редакторе движение изначально отсутствует; нажмите воспроизведение, затем включите общий переключатель.
2. Переведите фото в Free, поверните на 35°, включите вращение и hover-увеличение. Переместите, измените размер и угол: жесты должны работать, исходный поворот оставаться внешним.
3. Сгруппируйте разные элементы и назначьте группе вращение. Дочерние блоки должны двигаться вокруг общего центра. Проверьте Undo/Redo, блокировку и порядок слоёв.
4. Экспортируйте/импортируйте JSON и перезагрузите редактор. Затем сохраните облачный черновик и опубликуйте; сравните `/preview` и `/u/:username`.
5. На телефоне проверьте нижнюю панель и воспроизведение медиа: hover не должен запускаться от касания.
6. В DevTools включите reduced motion: движения прекращаются, текст/медиа остаются видимыми. Прокрутите блок за экран и верните: timeline приостанавливается и продолжается.

## Ограничения

Набор эффектов фиксирован; произвольные CSS, keyframes и внешние скрипты не принимаются. Группы остаются одноуровневыми. Границы прокрутки считаются по исходной композиции: анимационные выходы за её края не расширяют полотно, у края области просмотра часть эффекта может быть обрезана. При изменении геометрии анимация перезапускается, а не продолжается с прежней фазы. CSS-фильтры могут увеличить нагрузку при большом числе видимых медиа; максимальные значения ограничены, но реальная скорость зависит от устройства. Проверка настоящего Safari/iPhone и слабых устройств остаётся ручной.
