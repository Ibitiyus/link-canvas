# Mobile Editor 2.0: проверка

Ветка: `feat/mobile-editor-layer-controls`. База — актуальный `main`, включая `698caf9` с независимой прозрачностью фонов. История репозитория сохранена.

## Изменения

- `Editor.tsx`, `MobileEditorTools.tsx`, `direct-editor.css`: единое рабочее пространство, нижние панели, свайп высоты, safe-area / visualViewport, раскрытие настроек и прокрутка к выделению. Большая панель оставляет видимую часть композиции.
- `useCanvasGesture.ts`, `gestures.ts`, `SelectionHandles.tsx`: единый обработчик Pointer Events, удержание 350 мс, восемь ручек с областями 44 CSS px, преобразование масштаба, повёрнутый декор, отмена и одна запись истории на жест. Области ручек вынесены за поверхность, чтобы сохранить доступ к аудиоконтролам.
- `layers.ts`, `LayerList.tsx`, `Canvas.tsx`: общий порядок сетки и декора, четыре команды порядка, перетаскивание и клавиатурное управление слоями, видимость, закрепление, удержание для контекстных действий. Выделение рисуется над содержимым независимо от слоя.
- `grid.ts`, `ProjectContext.tsx`, `storage.ts`, `types.ts`, `defaults.ts`: защита геометрии закреплённых блоков, перераспределение вокруг них, незакреплённая копия, необязательные поля v1 и сохранение точной формы старых JSON.
- `Inspector.tsx`, `Library.tsx`, `CanvasViewport.tsx`, `Toolbar.tsx`, `blockIcons.ts`: управление новыми свойствами, точные размеры и масштаб; существующий renderer остаётся общим для редактора, предпросмотра и публичной страницы.
- `202610210001_editor_layers.sql`: отдельная миграция проверки типов `locked`, `hidden`, целочисленного `layer`. Прежние миграции сохранены.

## Автоматические проверки

| Команда | Результат |
| --- | --- |
| `npm run typecheck` | Пройдено |
| `npm test` | 93 теста пройдены |
| `npm run build` | Пройдено |
| `TEST_PRODUCTION=1 npm run test:e2e -- --workers=1 --retries=1` | 55 пройдены, 2 публичных сценария пропущены и проверены следующим прогоном |
| `npm run test:canvas -- --workers=1 --retries=1` | 23 пройдены, включая `/u/:username`, реальные bounding boxes и визуальные регрессии |
| `npm run test:cloud` | 42 проверки реального локального Supabase пройдены |
| `npm run test:e2e:cloud` | 3 сценария пройдены на локальном Supabase |

В браузерных командах этой среды использовались `XDG_CONFIG_HOME` и `XDG_CACHE_HOME` внутри `/tmp`. Финальные прогоны выполнялись в Chromium одним worker, без повторов сценариев. Число сценариев разных прогонов не складывается в число уникальных тестов.

Проверяются ширины 320, 390, 768, 1024 и 1440 px, а общая регрессия интерфейса также охватывает 1366/1920 px. Новые touch-сценарии используют CDP Touch Events: удержание, обычную прокрутку без изменения проекта, изменение размера, удержание строки слоя, блокировку и выбор, уменьшение видимой области при фокусе в поле. Реальные облачные сценарии проверяют регистрацию, перенос всех восьми типов и шрифтов, сохранение `locked/layer` в PostgreSQL, порядок публичного декора, медиа, переименование/снятие публикации и конфликты ревизий.

## Проверка перед выпуском

1. Применить новую миграцию обычным процессом миграций, без сброса базы; затем выпустить frontend. В рамках задачи миграция применялась только к локальному Supabase. Рабочие настройки Supabase/Vercel и пользовательские данные не менялись.
2. На ПК открыть старый проект, переместить блок за центр, изменить размер за стороны и углы, проверить одну отмену и отмену жеста через Escape.
3. На телефоне добавить блок, раскрыть/свернуть панель свайпом, удержать поверхность и переместить. Быстрый свайп должен прокручивать рабочую область. Проверить масштаб и возврат «По ширине».
4. Поместить декор за фотографию, выбрать его через слои, изменить порядок. Закрепить сеточный блок и декор; убедиться, что содержимое доступно, а геометрия защищена. Проверить незакреплённую копию и подтверждение удаления закреплённого элемента.
5. Перезагрузить, экспортировать/импортировать JSON, сохранить в облако и опубликовать. На другом устройстве проверить композицию, порядок, прозрачность, пользовательские шрифты и медиа. Для видео/ссылок/QR в редакторе использовать «Взаимодействовать с медиа».
6. На реальных iPhone и Android проверить системную клавиатуру, safe-area, прокрутку и долгие нажатия. Эмуляция visual viewport и touch в Chromium не заменяет эти проверки, как и проверку Safari.
