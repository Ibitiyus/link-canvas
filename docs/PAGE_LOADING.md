# Загрузка готового ZIN

В `/preview` и `/u/:username` композиция скрыта за прелоадером до готовности её ресурсов. `PagePreloader` сохраняет компоненты в DOM, поэтому видео и аудио не перемонтируются при открытии страницы, а размеры полотна вычисляются заранее. Анимации до открытия приостановлены; скрытое содержимое недоступно для кликов и клавиатуры (`inert`).

Отслеживаются изображения/GIF (в том числе обложки и фон страницы), разрешение ссылок IndexedDB/Supabase, установленные шрифты, первый кадр файлового видео, метаданные аудио и загрузка документа YouTube iframe. Видео и аудио не скачиваются целиком: они остаются потоковыми. Событие загрузки YouTube подтверждает загрузку встраиваемого документа; содержимое стороннего плеера ограничено политикой same-origin.

Загрузки не заменяются фиксированной задержкой. После окончания последнего запроса небольшой интервал стабилизации позволяет React добавить элементы, появляющиеся после разрешения файловых ссылок. Ошибки ресурсов завершают ожидание и показывают сообщение с повторной загрузкой. Через 30 секунд ожидания появляется выбор: повторить загрузку, продолжить ждать или явно открыть уже загруженную часть. Автоматического открытия незавершённой страницы по таймеру нет.

В режиме просмотра отсутствуют кнопки масштаба и обработчик `zin:zoom`. Полотно автоматически вписывается в ширину устройства, фон продолжает занимать весь экран. Настройки логической ширины и масштаб редактора сохранены. Формат проектов и облачная схема не менялись.

Проверка: `npm run typecheck`, `npm test`, `npm run build`, `npm run test:canvas -- --workers=1`. Последняя команда включает `tests/page-preloader.spec.ts` и публичный маршрут с локально подменённым HTTP API, не изменяя рабочий Supabase. В тестах задерживаются реальные сетевые ответы, проверяются ошибки, шрифты, GIF, аудио, видео, iframe, ручное продолжение и ширины 320/390/768/1440.

После деплоя откройте опубликованный `/u/:username` с выключенным кешем и замедлением сети в DevTools: до завершения загрузки должен оставаться экран ZIN, затем должна появиться целая композиция без кнопок масштаба. Проверьте фон на весь экран, переход по ссылке/QR и запуск музыки/видео. Повторите на телефоне или в эмуляции 390px. Для проверки ошибки заблокируйте один URL медиа: после ответа с ошибкой должен появиться доступный остальной контент и сообщение с кнопками повтора и скрытия.
