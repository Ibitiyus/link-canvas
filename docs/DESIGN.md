# ZIN — независимый интернет

Визуальный редизайн существующего приложения: Y2K / punk / cyber grunge / editorial brutalism. Основная идея — **ВАШ ИНТЕРНЕТ. ВАШИ ПРАВИЛА.**

## Система

Источник дизайн-токенов: [`src/styles/tokens.css`](../src/styles/tokens.css).

| Токен              | Цвет      | Назначение                           |
| ------------------ | --------- | ------------------------------------ |
| `--bg`             | `#0D0D0F` | Основной фон                         |
| `--surface`        | `#17171A` | Панели                               |
| `--surface-raised` | `#222226` | Активные поверхности                 |
| `--border`         | `#37373D` | Границы и разделители                |
| `--red`            | `#FF3355` | Главное действие, выделение, маркеры |
| `--pink`           | `#FF4FA3` | Вторичные акценты и hover            |
| `--deep-red`       | `#B80F36` | Акцент на светлой поверхности        |
| `--light-pink`     | `#FFB6CF` | Подписи и сообщения                  |
| `--paper`          | `#F2EFEB` | Основной текст, инверсия             |
| `--muted`          | `#97979F` | Вторичный текст                      |

Типографика: **Roboto Condensed** для плакатных заголовков, **IBM Plex Mono** для интерфейса и технических подписей. Латинские и кириллические подмножества подключены через Fontsource; шрифты поставляются вместе с приложением. Запросы к Google Fonts не нужны.

Геометрия: углы 0–2 px, рамки 1 px, резкие разделители, offset shadows. Нет glassmorphism, цветных свечений и скруглённых SaaS-карточек. Текстуры создаются вектором, штриховкой и мелким halftone. Общие компоненты `Brand`, `PanelHeader`, `Starburst` используют ту же систему.

Расчётный контраст базовых пар по WCAG (не аудит всех возможных пользовательских цветов):

- Вторичный текст / поверхность: **6.17:1**.
- Тёмный текст / красная кнопка: **5.41:1**.
- Светлый текст / основной фон: **16.94:1**.
- Розовый акцент / приподнятая поверхность: **5.21:1**.

## Страницы

- **Главная:** плакатный hero, красная строка манифеста, интерактивная песочница, нумерованный toolkit и завершающий CTA. Песочница использует настоящий `Canvas`, алгоритмы сетки и рендеринг блоков. Её состояние отдельно от сохранённого проекта. Переключатель просмотра включает ссылки и видео; в режиме редактирования работают перемещение и размеры.
- **Редактор:** техническая верхняя панель; библиотека «Блоки» / «Медиа» / «Декор» и «Слои»; полотно с нумерацией колонок; панель «Содержимое» / «Оформление» / «Эффекты» / «Размещение». Рабочие панели прокручиваются независимо; ручки и место назначения выделены красным.
- **Предпросмотр:** новая закрываемая информационная полоса. Само содержимое сохраняет пользовательское оформление.
- **404:** отдельная композиция со знаком бренда и рабочими переходами на главную и в редактор.

Несуществующие страницы входа, регистрации и публикации не добавлены.

## Изоляция пользовательской темы

Стили разделены по назначению:

```text
src/styles/
  tokens.css    палитра, шрифты UI, интервалы, размеры, рамки, эффекты
  base.css      сброс и общие интерактивные компоненты
  home.css      главная и песочница
  editor.css    панели, поля, toolbar, мобильная навигация
  canvas.css    отображение содержимого и отдельно маркеры редактора
  preview.css   полоса предпросмотра и страница 404
```

Цвет, шрифт, фон, радиус, рамка и непрозрачность пользовательских блоков приходят из `Project` через inline styles. UI CSS их не заменяет. Версия данных и ключ localStorage остались прежними. Миграции, удаления и перекраски сохранений нет. Новые демонстрационные значения применяются только к свежему проекту и при явном сбросе. Сохранённые фиолетовые страницы остаются фиолетовыми: это оформление пользователя, а не тема интерфейса.

Браузерный регрессионный сценарий загружает сохранённую белую страницу с зелёным блоком, шрифтом Georgia, скруглением 35 px и непрозрачностью 0.8; проверяет отображение в редакторе/предпросмотре и полное равенство сохранённых данных после reload.

## Адаптивность и движение

- До 1050 px библиотека, полотно и настройки становятся отдельными переключаемыми панелями.
- Добавление блока открывает его свойства; вкладка «Полотно» возвращает к размещению. Выбор при начале перетаскивания не переключает панель, поэтому жест не прерывается.
- На смартфонах библиотека перестраивается по группам; поля ввода увеличены до 16 px, чтобы избежать автоматического масштабирования в iOS.
- Проверены ширины **320, 390, 768, 1024, 1366 и 1920 px**, включая размещение кнопок внутри toolbar и отсутствие горизонтального переполнения.
- Декоративное появление короткое и однократное. Нет постоянного glitch/мерцания и тяжёлых эффектов во время drag-and-drop.
- `prefers-reduced-motion` отключает декоративные анимации и показывает статичный вариант GIF в песочнице. Пользовательские медиа в настоящем проекте не заменяются.

## Медиа песочницы

В `public/demo` находятся локальные SVG-постеры, анимированный GIF и короткий WebM без аудио. Внешние сервисы для демонстрации не нужны. Пользовательские изображения/видео по-прежнему работают по HTTP(S) URL; YouTube использует безопасное встраивание на `www.youtube-nocookie.com`.

## Проверки

Прошли TypeScript-проверка, production build, 23 модульных теста Vitest и 17 браузерных сценариев Playwright на dev- и production-серверах. Существующие модульные тесты и сценарии редактора сохранены. Добавлены браузерные проверки изоляции пользовательской темы, песочницы, адаптивности, мобильных панелей, reduced motion и 404. Команды:

```sh
npm run typecheck
npm test
npm run build
npm run test:e2e
TEST_PRODUCTION=1 npm run test:e2e
```

На Windows последнюю команду запускайте через PowerShell: `$env:TEST_PRODUCTION="1"; npm run test:e2e`. Настройка домашнего каталога браузера в облачной среде описана в основном README.

Ограничения приложения прежние: один локальный проект в браузере, без аккаунтов, синхронизации и публичной публикации. Возможность реального воспроизведения внешних медиа зависит от сети и владельца ресурса; доступность YouTube из облачной машины по-прежнему ограничена.
